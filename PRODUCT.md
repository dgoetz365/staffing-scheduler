# Fieldwork Scheduler

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Python 3.12 standard library, SQLite, semantic HTML, CSS and vanilla JavaScript. No external dependencies or services.

## Users
A single local operator evaluating a fictional community science exhibition volunteer schedule.

## Product Purpose
Make assignment constraints visible, publish a complete immutable schedule, and review subsequent reassignment requests without silently changing that publication.

## Capabilities and Constraints
Availability windows, eligible roles, shift capacity, overlap rejection, optimistic version checks, transactional mutations, publication history and approve/decline requests. Local single-user demonstration only, with no authentication or hosted-service claim.

## Evidence on Hand
All people, stations, shifts and events are invented. No employer implementation or data is used. The user directed immediate implementation without browser use or further questions; product details and naming are inferred from this brief.

## Product Principles
Explain a rejected assignment; keep publication separate from draft; make stale edits recoverable; preserve a readable audit trail.

## Accessibility & Inclusion
Semantic controls, visible keyboard focus, text status, a responsive document, and reduced-motion support.
